COMO ABRIR:
1. Extraia a pasta sono_conectado.
2. Abra a pasta no Visual Studio Code.
3. Instale a extensão Live Server.
4. Abra index.html e clique com o botão direito > Open with Live Server.

COMO FUNCIONA?
- Na primeira visita, clique em Cadastre-se.
- Crie um nome de usuário e uma senha.
- Entre com os mesmos dados.
- Use o botão Sair para encerrar a sessão.
- Rotinas, tarefas e reflexões ficam separadas por usuário neste navegador.

IMPORTANTE!!
Este login é local e demonstrativo. As contas e os dados ficam no armazenamento do navegador e não são compartilhados entre dispositivos ou navegadores.
A senha é armazenada como hash, mas isso NÃO é autenticação segura para produção: alguém com acesso ao navegador/dispositivo pode manipular os dados locais.
Não use senhas pessoais, bancárias ou reutilizadas.

ARQUIVOS:
- index.html: telas do site e login/cadastro.
- style.css: aparência.
- script.js: login local e funcionalidades.
